# Weather Outfit

A weather-aware outfit recommendation web application designed to help you decide what to wear based on current and forecasted weather conditions.

## Motivation

Weather apps tell you what the weather is.

Weather Outfit aims to bridge that gap by combining weather conditions with clothing recommendations focused on comfort.

## Project Status

**Developing**

Currently working on the core weather-data layer and project architecture.
